# 07 - Uso de Inteligência Artificial

## 1. Declaração de uso

Durante o desenvolvimento do **CompraAudit**, ferramentas de inteligência artificial generativa foram utilizadas como apoio ao processo de desenvolvimento, documentação e revisão.

As ferramentas utilizadas foram:

* DeepSeek;
* Gemini.

---

## 2. Finalidade do uso

As ferramentas de IA foram utilizadas como apoio para:

* organização de ideias
* revisão de textos
* estruturação da documentação
* apoio na depuração de erros
* sugestões de melhoria de código
* apoio na organização do fluxo do projeto
* apoio na preparação do README e demais documentos.

---

## 3. Limites do uso

A IA foi utilizada apenas como ferramenta auxiliar.

As decisões finais de implementação, validação, testes, arquitetura, integração com blockchain e submissão do projeto foram realizadas pelo participante responsável.

O projeto foi executado, testado e validado manualmente durante o desenvolvimento.

---

## 4. Responsabilidade

O participante responsável pelo projeto declara que:

* compreende a lógica da solução
* consegue explicar o funcionamento do código
* validou o fluxo principal do MVP
* testou a integração entre frontend, backend e blockchain
* revisou os conteúdos gerados ou apoiados por IA antes da submissão

---

## 5. Ferramentas declaradas

| Ferramenta | Uso no projeto                                                              |
| ---------- | --------------------------------------------------------------------------- |
| DeepSeek   | Apoio em dúvidas técnicas, revisão de código e organização de ideias        |
| Gemini     | Apoio em revisão textual, estruturação de documentação e sugestões técnicas |
